# Data

| Folder | Contents | In git? |
|---|---|---|
| `motions/raw/` | animal mocap and other source clips | No, share via team drive |
| `motions/retargeted/` | clips retargeted to the robot (`.npz`, see `motions/format.py`) | Yes |
| `motions/trajopt/` | gaits generated by trajectory optimization (`.npz`) | Yes |
| `sysid/raw/` | swing-test and motor logs, scale readings | No |
| `sysid/processed/` | fitted parameters and measurement summaries | Yes |
| `hardware_logs/` | recordings from hardware runs | No |
