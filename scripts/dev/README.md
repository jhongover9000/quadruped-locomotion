# Developer diagnostics

Shell scripts for checking the training machinery on this workstation. Both use the GPU
and activate the `mujoco` conda env themselves. Run them from anywhere: each finds the
repository root from its own location. The optional first argument is the folder for
logs and runs. It defaults to a folder under `outputs/debug/`, which git ignores.

| Script | What it checks | Run |
|---|---|---|
| `stall_test.sh` | The stall watchdog and resuming. It starts a real SuperMimic run (256 envs), freezes the training process with `SIGSTOP` after iteration 200, and checks that the supervisor ends the run with exit code 75. It then runs `--continue-run` for about 20 s. It exits 0 only if the exit code was 75, `ckpt_latest.pt` exists, and the continued run resumed from iteration 100 or later. | `scripts/dev/stall_test.sh [work_dir]` (default `outputs/debug/stall_test`) |
| `run_stages.sh` | The local smoke pipeline (`SMOKE=1 hpc/submit_pipeline.sh --local`), one stage at a time. Each stage gets up to `ATTEMPTS` (5) attempts with a hard limit of `ATTEMPT_LIMIT_S` (3000 s) each, because fresh Python processes on this machine sometimes hang during import. Each attempt runs in its own process group; it is killed as hung (the whole group) when its log has not grown for `HANG_S` (300 s) and the GPU memory in use is below `HANG_GPU_MIB` (300 MiB; hangs happen before CUDA init, while quiet rendering or compiling holds GPU memory). If `nvidia-smi` fails, only the hard limit applies. Under WSL it also checks that the GPU passthrough is up (the driver mount `/usr/lib/wsl/drivers` is readable) before each attempt and at every poll; when it is lost, the run stops at once with exit code 3 and the time of the loss in the log, since only `wsl --shutdown` brings the GPU back. Each attempt's log is kept as `stage_<name>_<attempt>.log`. It stops at the first stage that fails all its attempts, prints a summary table (result, attempts, hangs killed, wall time) and exits non-zero if a stage failed. | `scripts/dev/run_stages.sh [log_dir]` (default `outputs/debug/run_stages`); `STAGES="ppo evaluate"` runs only some stages; `PIPELINE_ID` (default `smoke_local`); `POLL_S` (20 s); `STAGE_CMD='...'` runs that shell command as each stage (`$STAGE` set) to test the driver itself |
| `stance_sweep.py` | Holding torque of candidate standing poses (CPU only, plain MuJoCo, no GPU). It settles the robot on a flat floor from each pose for 3 s under the config's PD gains, torque limit, armature and joint friction, as the importer's standing test does, and reports the mean \|torque\| over the last 1 s (largest over the legs) for hip, thigh and calf, with and without joint frictionloss, plus trunk height and whether only the feet touch. Grid: thigh x calf with hip 0, then inward hip abduction at the best pair. Writes a Markdown table sorted by the largest frictionless torque. | `python scripts/dev/stance_sweep.py [--robot astra] [--thigh ...] [--calf ...] [--out path]` (default `outputs/debug/astra/stance_sweep.md`) |

The shell scripts should not run while another job is using the GPU.
